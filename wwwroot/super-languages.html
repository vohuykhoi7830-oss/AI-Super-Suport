🔗 Chia sẻ ứng dụng

Để share cho người khác truy cập từ bất kỳ đâu, dùng ngrok — công cụ miễn phí tạo đường dẫn công khai tức thì.

1

Tải ngrok: ngrok.com/download → Đăng ký miễn phí → Lấy authtoken

2

Mở terminal VS Code, chạy app rồi chạy lệnh: ngrok http 5122

3

Ngrok sẽ cấp 1 URL dạng: https://xxxx.ngrok-free.app — Share link này cho bạn bè!

4

Tùy chọn nhanh hơn: VS Code → Extensions → Live Share → Share server port 5122

💡 Lệnh đầy đủ trong VS Code terminal:
dotnet run (terminal 1) → ngrok http https://localhost:5122 (terminal 2)
